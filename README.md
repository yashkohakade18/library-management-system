📚 Library Management System

A simple Library Management System built using Spring Boot and HTML, CSS, JavaScript to manage books with basic CRUD operations.

🚀 Features
Add, update, delete books,View all books

REST API integration

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: Spring Boot (Java)

Database: MySQL

![App Screenshot](/images/home.png)
⚙️ Run Locally
git clone https://github.com/your-username/library-management-system.git

cd library-management-system

mvn spring-boot:run

Open index.html in browser.

🔌 API

GET /api/books

POST /api/books

PUT /api/books/{id}

DELETE /api/books/{id}
